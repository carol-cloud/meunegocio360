# Projeto MeuNegocio360 - Documento de Requisitos (Frontend)
- Stack utilizada: React JS com Vite
- Paleta de cores: devem ser definidos como estilos globais da aplicação.
    - Laranja: #EC4E26 (botões primários, barra de navegação e texto de botões onHover e secundários);
    - Creme: #FCF5F0 (fundo das páginas e cartões);
    - Cinza: #3E3C3B (linha das tabelas, bordas dos cartões e texto secundário);
    - Preto: #1F1612 (texto principal)
    - LAranja amarronzado claro: #CDBBAE (rodapé)
- Fonte:
    - Barlow Condesed (pesos 500, 600 e 700): para titulos.
    - Barlow (pesos 400, 500 e 600): para textos, tabelas e rodapés.
